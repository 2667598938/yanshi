# 已创建自习室修改类型

进入自己的自习室，点右上角设置，在“房间管理 → 房间类型”选择文字或音视频，然后保存。普通成员的设置不显示此入口，接口也仅允许房主修改。

- 文字房可以选择20、50、100人的成员上限。
- 音视频使用mesh，最多6人；需要站点已开放且房主具有VIP或房间授权，与创建新音视频房的规则一致。原有成员访问音视频房仍受各自权限限制。
- 当前成员超过目标容量时拒绝保存并提示先调整成员，不自动移除任何人；类型与容量修改和加入房间共用写锁。
- 切换保留原房间ID、房间码、私密/公开设置、成员、留言、目标和学习记录。没有数据库迁移。
- 切换到音视频只显示入口，不自动开启摄像头或麦克风。切回文字房会销毁当前页面的媒体组件；其他在线连接在服务端下一次权限复核时关闭，正常间隔最多约5秒。
- 只改名称或简介时不重设原有类型或容量；SFU仍受原有部署开关限制。

回归覆盖双向切换、数据保留、越权、功能关闭/无授权、超员回滚、错误容量、SFU门禁、加入与切换并发，以及在线媒体撤权。前端覆盖房主入口、成员隐藏、容量提交、保存失败保留表单、媒体组件卸载和普通改名不改类型。
