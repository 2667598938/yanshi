## 1. 用户画像与角色

### 1.1 三类角色

| 角色 | 权限边界 |
|---|---|
| **游客** | 只能看登录页、首页介绍内容；不能发帖、不能加入房间 |
| **普通用户** | 注册即用；资料链接脱敏；部分功能需申请权限；可建公开房间 |
| **VIP 用户** | 邀请码开通或**管理员后台授予**（可设有效期）；可见完整链接+提取码；任意房间；无需申请；**可配自己的 AI Key** |
| **管理员（1 名）** | 生成邀请码、审批功能申请、管理内容与文案；**不可修改他人学习数据**，不可删除账号（改为封禁） |

### 1.2 典型用户画像

**小A · 图书馆备考党（主用户）**
> 大四考研，图书馆信号差，手机常年 4G/WiFi 来回切。每晚回宿舍才联网。核心诉求：**断网时番茄钟不能停**，数据第二天自动补传。

**小B · 自习室氛围党**
> 二战在家，缺乏氛围。核心诉求：看到别人在学（隐含需求：**最好能隐身**，不想被比较）→ 隐私模式是她的刚需。

**小C · 资料分享者**
> 收集网盘资料，愿意分享。痛点：资料链接被爬、被滥用 → 需要脱敏保护 + VIP 可见完整链接的分层。

## 2. 用户故事地图

```
【成为用户】         注册 ── 邮箱验证码登录 ── 完善昵称头像 ── 升级VIP(邀请码)
      │
【日常主线】         开始番茄 ── 专注中(可暂停) ── 结束(完成/放弃)
      │                                    │
      │                              超时自动quit
      │                                    │
      ├──► 【回顾】  今日/周/月扇形统计 ── 番茄明细
      │
      ├──► 【错题】  拍照录题 ── 艾宾浩斯排期 ── 到点提醒 ── 复习打卡 ── 掌握状态流转
      │
      ├──► 【陪伴】  进打卡自习室 ── 看在线成员 ── 房间留言 ── 今日排行榜
      │                └─ 视频小房间 / 云端视频室（等审核/被踢/解散）
      │
      ├──► 【资源】  浏览资料 ── 脱敏链接 ── 收藏 ── 我发布的资料
      │                └─ 需要完整链接 → 提交功能申请 → 等管理员审批 → 消息+邮件通知
      │
      └──► 【社区】  看帖子 ── 发帖子 ── 一级评论 ── 删自己的内容
                       └─ 励志区文案轮播 / 梦校墙浏览
                       └─ AI 问答（可选，依赖 Key）
```

**开发顺序建议**（按主线依赖）：`登录` → `番茄钟` → `同步引擎` → `错题本` → `自习室` → `资料区` → `帖子/励志区` → `AI`。

> 为什么同步引擎排第 3：它是所有离线模块的底座，等到做完番茄、错题再补同步，等于重写数据层。

> **入口永不隐藏**：非 VIP 点进来走 `53` 引导态（说明 + 开通 VIP + 提交申请），而不是让用户看不到这个功能存在。这与 `gap-report` G-13「视频房间连灰显入口都没有」是同一类错误，不许再犯。

## 4. 关键用例与验收标准

### UC-01 邮箱验证码登录
> **Given** 我是新用户 **When** 输入 QQ 邮箱并请求验证码 **Then** 60 秒内不能再发，收到 6 位验证码，5 分钟内有效，验证成功后自动注册并登录，跳转首页。

- 邮箱格式必须为 QQ 邮箱正则 `^[1-9]\d{4,10}@qq\.com$`，否则拒绝请求（不要发了才发现）
- 同一邮箱 5 分钟内最多 3 次请求；同一 IP 每小时最多 20 次，超限返回 `429 RATE_LIMIT`
- 验证码错误 5 次后该验证码立即作废
- 验证成功 → 返回 `access_token(30min)` + `refresh_token(7d)`
- **验收**：弱网下重复点击"获取验证码"只能收到 1 封邮件（幂等）

### UC-02 番茄超时自动放弃
> **Given** 我开启了 25min 番茄并忘记关闭 **When** 有效果计时达到 180 分钟 **Then** 系统自动结束该番茄，`status=quit`、`end_reason=timeout`、`actual_minutes=180`，且不再继续计时。

- 「有效果计时」= `now - start_at - pause_total`（暂停时间不计入上限）
- 前端 tick 判定；页面唤醒（`visibilitychange`/重载）二次校正；后端 `POST /tomato/end` **重算兜底**，不信任前端值
- **验收**：手工把 `start_at` 改成 3 小时前并重载页面 → 立即超时结束；改客户端系统时间无效（用服务端校正时间戳）
- **验收**：超过 180min 后产生的 180 分钟**计入统计时长**，但**不计入"完成番茄数"**

### UC-03 番茄暂停
> **Given** 番茄进行中 **When** 我点击暂停 **Then** 计时暂停；再次点击继续，累计暂停时长从总时长扣除。

- 单次暂停超过 **30min** → 该番茄自动 `quit(pause_timeout)`
- 多次暂停各自独立计时（A 暂停 10min+ 继续 + B 暂停 25min 不会触发 30min 上限）
- **验收**：暂停 31 分钟后查看记录，`status=quit`、`end_reason=pause_timeout`，`actual_minutes` = 暂停开始前已累计时长

### UC-04 休息循环
> **Given** 番茄正常完成 **When** 短休息倒计时结束 **Then** 必须用户手动点击「开始下一个番茄」，系统不自动开启。

- 连续完成 4 个（可自定义 1–8）番茄后进入长休息
- **验收**：休息归零后页面停在该状态不动，30 分钟后仍是等待手动开始（防止无人挂机刷时长）

### UC-05 统计扇形图
> **Given** 我有今日多条番茄记录 **When** 打开统计页 **Then** 日/周/月扇形图按**专注时长**分布展示。

- 数据源：**先读本地 Dexie**（秒出），同步完成后用服务端汇总值校准
- **验收**：断网状态打开统计页，数据完整可见（不出现"加载失败"）

### UC-06 离线创建番茄并同步
> **Given** 我处于断网 **When** 完成一个番茄 **Then** 写入 Dexie 并进入 outbox 队列；**当** 网络恢复 **Then** 自动同步至服务端，队列清空。

- **验收**：断网连刷 3 个番茄 → 联网后服务端恰好 3 条，**无重复、无丢失**
- **验收**：同步进行中断网 → 未成功的条目保留在队列，恢复后继续（成功的不重复提交）

### UC-07 同步冲突处理
> **Given** 我在线修改了 A 记录，离线期间另一设备也改了 A **When** 同步时服务端 revision 与本地 base_rev 不一致 **Then** 弹出冲突对话框，**展示本地/云端双版本对比**，用户二选一。

- 选「保留本地」→ 携带新 rev 强覆盖；选「用云端」→ 本地记录被服务端版本覆盖并清理 outbox 该项
- **验收**：冲突后无论选哪个，**最终两端数据一致**（再同步一次应无冲突）
- 一期**不做字段级合并**

### UC-08 邀请码开通 VIP
> **Given** 我持有有效邀请码 **When** 在个人中心输入并提交 **Then** 立即升级 VIP，无需审核。

- 邀请码一次性核销（`status=used`），重复使用返回错误
- **验收**：同一邀请码第二次使用必须失败，并提示"邀请码已使用"

### UC-09 功能申请与审批
> **Given** 我是普通用户 **When** 提交某项功能使用申请 **Then** 管理员可在后台看到待审列表；**当** 管理员通过/驳回 **Then** 我收到**站内消息 + QQ邮件**（驳回含原因）。

- 状态流转：`pending → approved | rejected`；`pending` 状态下用户**可撤回**；`approved` 后可由管理员 `revoked` 终结
- 驳回原因必填（≥5 字）
- **权限落地**：通过时**同一事务**写 `user_feature_grant`；鉴权只读授权表（`is_vip() or grant_exists(item_key)`），**不读申请状态**
- **验收**：用户撤回后，管理员列表该申请消失，不能再次审批（乐观锁）
- **验收**：审批后站内消息 + 邮件都收到，且**只有一份**（唯一索引防重）
- **验收**：审批通过的瞬间，被授予的功能即可用（同一请求返回后立刻请求受限接口应 200，撤销后立刻 403）

### UC-10 隐私模式
> **Given** 我在自习室开启了隐私模式 **When** 其他成员查看成员列表 **Then** 只能看到灰色占位「隐身学习中」，看不到我的昵称、头像、番茄状态、今日时长，且我不出现在房间排行榜。

- 我本人自己的视图不受影响（能看到自己的数据）
- 该状态**服务端持久化**并纳入同步，切换即时生效
- 我仍**计入在线人数**
- **验收**：开启后立即请求成员列表 API，返回的 JSON 里**不含**任何真实昵称/时长字段（不是前端遮住）

### UC-11 自习室心跳
> **Given** 我在房间内 **When** 每 30s 上报心跳 **Then** 在线；**当** 90s 无心跳 **Then** 判定离线，成员列表标记离线。

- 切后台/关页面触发离线
- **番茄不受影响**：离线判定不改变番茄记录的完成状态（番茄以自身流转为准）
- **验收**：杀掉浏览器进程，90 秒后其他端看到该成员已离线

### UC-12 资料脱敏
> **Given** 我是普通用户 **When** 查看资料区 **Then** 网盘链接中间部分被掩码、提取码不可见；**当** 我是 VIP **Then** 完整链接与提取码可见。

- 掩码规则：保留协议与域名，路径段中间 6 位替换为 `******`
- **验收**：调用接口返回的原始 JSON 中普通用户拿不到完整链接字段（后端脱敏，非前端替换）

### UC-13 错题艾宾浩斯排期
> **Given** 我新增一道错题 **When** 到达复习节点 **Then** 出现在"今日待复习"；**当** 我点击掌握/需巩固 **Then** 推进或回退下一节点。

- 8 节点：5min / 30min / 12h / 1d / 2d / 4d / 7d / 15d（一期固定）
- 状态：`pending` → `mastered`（终止排期）/ `restrengthen`（回退到上一节点）
- **验收**：离线状态下复习打卡也生效，联网后同步且 **stage 不倒退**

### UC-14 管理员内容管理
> **Given** 我是管理员 **When** 删除一条违规帖子 **Then** 该帖子下线，作者收到站内消息 `content_deleted`。

- 管理员不可修改他人番茄、错题、学习统计
- 删除均为**软删**（`deleted_at`），保留追溯能力
- **验收**：普通管理员视角不存在"编辑番茄记录"入口；直接调 API 也返回 403

### UC-15 AI 问答（方案 B：用户自填 Key）
> **Given** 我是 **VIP** 用户且已填写自己的 API Key **When** 在 AI 页提问 **Then** 后端解密我的 Key 调用第三方大模型并返回结果。

**前置**：普通用户进入 AI 页 → 展示「该功能需 VIP + 配置自己的 API Key」引导，不提供任何输入框。

**支持的模型（不硬编码，架构上"无限"）**

| 预设服务商 | Base URL | 说明 |
|---|---|---|
| **DeepSeek**（推荐默认） | `api.deepseek.com/v1` | 便宜、中文强、含推理模型 |
| **月之暗面 Kimi** | `api.moonshot.cn/v1` | 长上下文，适合长题面 |
| **智谱 GLM** | `open.bigmodel.cn/api/paas/v4` | 有免费额度 |
| **硅基流动 SiliconFlow** | `api.siliconflow.cn/v1` | 一个 Key 用多家开源模型 |
| **OpenAI** | `api.openai.com/v1` | 需自备网络 |
| **自定义** | 用户手填 | OneAPI / NewAPI 中转、本地 Ollama、vLLM |

- 统一走 **OpenAI 兼容协议**；模型列表由后端用用户 Key 调 `/v1/models` **实时拉取**，不会因版本迭代过期；拉取失败可手填模型名
- 输出为**流式**（逐字返回），超时 60s
- **上下文：携带最近 N 条历史，按条数截断**（默认 N=10，可选 5/10/20）；一期不做 token 精确计算
- **用量可见**：单条对话展示本次 token 消耗与耗时（`ai_chat.prompt_tokens / completion_tokens / latency_ms`）
- 能力边界与演进：**P0 纯文本问答 → P1 图片输入 + token 精确截断 + 用量面板 → P2 function calling / 联网 / Agent**，详见 `02-ARCH` **ADR-012**

**Key 管理（UC-15a）**
> **Given** 我是 VIP **When** 在「个人中心 → AI 设置」填入 Key 并保存 **Then** 后端加密存储；**查看时**只显示掩码 `sk-...abcd` 与配置时间。

- 保存可做一次轻量校验请求，失败提示「Key 无效或额度不足」（**不回显 Key 片段**）
- 可随时删除（删除后 AI 功能停用，历史对话保留）
- **验收**：抓包看不到完整 Key；页面刷新后输入框**不回填明文**；DB 直接查表得到的是密文

**安全红线**
- 前端不落 `localStorage` / Dexie，输入即提交，提交后内存即弃
- 后端 AES-256-GCM 加密，主密钥 `AI_KEY_ENC_SECRET` 只在 `.env`
- 第三方请求在**服务端**发出，前端只拿到模型回复
- 调用限流：单用户 10 次/分钟、200 次/天（防滥用刷量）

### UC-16 管理员调整 VIP
> **Given** 我是管理员 **When** 在后台用户管理中调整某用户的 VIP（开通/续期/设置到期时间/降级） **Then** 立即生效，并给该用户发一条站内消息；**当** 设置为「开通/续期」**Then** 同时发送邮件通知。

| 操作 | 效果 | 通知 |
|---|---|---|
| 开通 | `vip_level=1`，`vip_expire_at` 可空（永久）或指定日期 | 站内 + 邮件 |
| 续期 / 改到期日 | 更新 `vip_expire_at` | 站内 + 邮件 |
| 降级撤销 | `vip_level=0`，已填的 AI Key **保留但停用** | 仅站内消息 |
| 备注 | 每次操作必须填 `remark`（≥5 字），写入操作日志 | — |

- **验收**：降级后该用户立即看不到完整网盘链接、无法使用 AI（Key 未被删除，恢复 VIP 后立即可用）
- **验收**：到期任务每天扫描 `vip_expire_at < now` → 自动置 `vip_level=0` 并发站内消息
- **验收**：所有 VIP 变更在 `admin_operation_log` 中可查（操作人/时间/前后值/备注），管理员自己也不能删日志

### UC-17 番茄双计时模式 + 学习内容
> **Given** 我在番茄页 **When** 选择「倒计时」**Then** 按计划时长倒数，归零提示完成；**当** 选择「正向计时」**Then** 从 0 开始正计时，无结束提示，我手动结束。

- 两种模式都可填**学习内容**（如"数学-线代"），可下拉选历史内容或手输
- **正向计时仍受 180min 上限保护**：达上限自动 `quit(timeout)`（防挂机），`planned_minutes` 记为 0
- 倒计时模式：结束状态 `done`；正向计时：手动结束记 `done`，时长取真实值
- **验收**：正计时跑到 3 小时自动结束并记 180min；切换模式不丢失正在进行的番茄（切换需先结束）

### UC-18 热力图与年度统计
> **Given** 我打开统计页 **When** 切换到「年」**Then** 看到全年日历热力图（每格 = 一天）+ 年度扇形统计。

- 热力图按当日专注时长分 **5 档**着色（0 / <30min / <1h / <2h / ≥2h），低饱和配色，与全站风格一致
- 支持点击某天查看当日番茄明细
- 扇形统计维度：**按学习内容分类**占比（日/周/月/年同一套口径）
- 数据源同 UC-05：本地 Dexie 优先，同步后校准
- **验收**：断网时热力图与年统计照常渲染；跨时区不串天（按本地时区归日）

### UC-19 错题拍照录入 + 自定义错误类型
> **Given** 我新增错题 **When** 分别拍照「题目」与「解析」**Then** 两张图独立存储；**当** 填写错误类型与主要思路 **Then** 保存并在复习时展示。

- 字段：题目图 `question_img` / 解析图 `answer_img`（各自七牛 URL）/ 题面文本 / **主要思路** / 答案解析 / 标签 / **错误类型**
- **错误类型支持用户自定义**：系统预置 6 类（概念不清/计算错误/审题失误/方法不会/记忆模糊/粗心），用户可增删改自己的类型（存 `user_error_type`）
- **验收**：只拍照不填文本也能保存；错误类型下拉含"自定义类型"且可管理

### UC-20 自习室创建 / 公开私密 / 邀请 / 虚拟形象
> **Given** 我创建自习室 **When** 选择「私密」**Then** 仅受邀成员可进；**当** 我分享邀请链接或房间码给好友 **Then** 好友凭码直接进入，无需我审核。

- 私密房间：凭**邀请码/邀请链接**加入免审；陌生用户搜索不到，申请入房走房主审核
- 成员列表展示：**虚拟形象 + 昵称 + 当前状态**（专注中/休息中/空闲/离线）+ 今日时长（隐私模式隐藏）
- 虚拟形象：系统预设 8–12 款（存七牛或内置 SVG），用户在个人中心选择；离线降级为默认形象
- 房主：踢人、解散、改名、改简介、重新生成邀请码
- **验收**：私密房间未受邀用户直接访问 → 403 且列表不出现；邀请码失效后不可再加入

### UC-21 励志区 UGC 投稿审核
> **Given** 我是任意用户 **When** 投稿一张图片 + 一句文案 **Then** 状态为「待审核」；**当** 管理员通过 **Then** 该内容进入轮播池，我收到站内消息；**驳回** 则收到含原因的通知。

- 所有人可投稿（含普通用户），**审核前不公开展示**
- 管理员后台：待审队列（缩略图 + 文案 + 投稿人）→ 通过 / 驳回（填原因）
- 审核通过后按 `sort` 随机轮播淡入
- **验收**：未审核内容在任何公开接口都查不到；驳回后投稿人收到通知

### UC-22 评论嵌套回复
> **Given** 我看到一条评论 **When** 点击「回复」**Then** 生成二级回复，显示"回复 @某人"。

- **最多二级**：对二级评论的回复，仍归到其父评论下（平铺 + 前缀"回复 @X"），不产生第三层
- 删除：作者删自己的、楼主可删楼内任意评论、管理员删任意
- **验收**：回复层级不超过 2；删除父评论时子回复一并软删

### UC-23 离线发帖
> **Given** 我处于断网 **When** 发布帖子 **Then** 写入本地 Dexie 并标记「待同步」，UI 显示"待上传"角标；**联网后** 自动同步上架。

- 帖子纳入同步范围：带 `uuid` / `revision` / `outbox`
- **只允许作者本人修改自己的帖子**，因此冲突面很窄（多端改同一帖才冲突，走二选一）
- **验收**：断网发 2 帖 → 联网后服务端恰好 2 条且顺序一致；同步前**别人看不到**（本地草稿性质，UI 明确标注"仅本机可见"）

### UC-24 资料权限与点赞
> **Given** 我是普通用户 **When** 打开资料区 **Then** 可浏览标题/简介/分类，链接隐藏；**当** 我尝试上传 **Then** 提示"仅 VIP 可发布资料"并引导；**当** 我是 VIP **Then** 可发布并对任意资料点赞。

- 上传权限：**仅 VIP**（普通用户上传入口置灰 + 后端 403 双保险）
- 查看：非 VIP 链接脱敏（保留协议域名，路径中间 6 位 `******`），提取码不可见
- 点赞：`(user_id, resource_id)` 唯一，可取消；点赞数走服务端计数（不走同步，在线动作）
- **验收**：普通用户直接调上传接口返回 403；普通用户拿到的接口响应中**不含完整链接字段**

## 5. 非功能需求

| 类别 | 指标 |
|---|---|
| **性能** | 首屏（移动端 4G）≤ 2.5s；番茄开始按钮点击到计时响应 ≤ 100ms；统计页本地渲染 ≤ 300ms |
| **离线能力** | 断网可用模块：番茄、错题、资料收藏、个人资料；不可用：房间、帖子、资料列表、AI |
| **同步可靠性** | 单次 sync 失败不影响本地；重试指数退避 1/2/4/8s；本地数据**永不自动清除** |
| **兼容性** | Chrome / Edge / Safari(iOS 15+) 最近两个大版本；移动端 360px 宽度起不横向滚动 |
| **可用性** | 关键操作（番茄结束、审批）必须落持久层后才给 UI 成功反馈 |
| **安全** | 全站 HTTPS；密码类无；token 不落 localStorage；上传走 magic bytes 校验；所有写接口鉴权 |
| **可维护性** | 后端分层清晰（router → service → dao）；前端无跨层直连 API；单一 Table 的 SQL 只允许写在 dao |
| **容量（一期）** | 目标 1000 注册用户 / 日活 100 / 单机 MySQL 足够 |
| **可观测** | 结构化日志 + `trace_id` 贯穿；错误日志自动带上 user_id 与 path |

## 8. 社区：圈子与共享（二期草案 · 未进一期排期）

> **状态**：草案，**未评审通过、未进排期**。不在 §7 冻结清单内，但也不在一期范围内。一期仍是"单间自习室"（F-20/F-21 原样）；本节描述把它升级成「圈子 → 房间」两层后的目标态，供二期评估。落地前不改一期任何接口与表。
>
> **一期开发者请跳过本节**，但要知道它将来会动哪些一期条款——见下方「8.0 生效边界」。一期照 §6 的 F-20/F-21 做不会被本轮改动影响。

### 8.0 生效边界（二期落地时要一起改的一期条款）

| 一期条款 | 现在写的 | 二期改成 |
|---|---|---|
| F-21 邀请分享 | 邀请链接 / **房间码** | 码升级为**圈子码**，房间不再单独发码 |
| UC-20 准入规则 | 私密房间凭码免审 / 陌生人申请走**房主**审核 | 同一套规则上移到**圈子**，房间继承圈籍 |
| 屏 12 创建自习室 | 选「公开 / 私密」 | 变成创建**圈子**（四档可见性），房间在圈内开 |
| 屏 37 补·入房申请 | 房主审核入房 | 变成**圈主审核入圈**，房间不再单独审 |
| `room.invite_code` | 房间码字段 | 废弃，改由 `circle.join_code` 承担 |

> **两个数字别混**：圈子 `member_limit` 默认 20（上限 50）是"这个圈子能装多少人"；房间容量是"一间房同时几个人在线"（原型为 4 席，一期不变）。二者无关系，不要合并成同一个配置项。

### 8.1 三层结构

| 层 | 生命周期 | 承载什么 |
|---|---|---|
| **大社区** | 常驻 | 公共广场，**只展示圈子，永远不展示个人** |
| **圈子** | 长期（像群） | 成员名单、共享档位、圈内看板、错题池 |
| **房间** | 临时（几小时） | 「现在一起学」的场所；关闭后不留独立数据 |
| **个人** | — | 共享档位由本人控制，**圈主与管理员都无权代开** |

**数据沉淀规则**：番茄记录永远属于用户本人；看板数字由服务端按 `circle_id` 聚合，房间不产生数据副本。一个人同时在 3 个圈子，三个圈子各自独立聚合，互不泄露。

### 8.2 圈子准入（四档）

| 档位 | 探索页可见 | 加入方式 | 默认 | 适用 |
|---|---|---|---|---|
| `public` 公开·直进 | 是 | 点击即加入 | | 大群、公开自习圈 |
| `public_review` 公开·需审核 | 是 | 提交申请 → 圈主通过 | | 有门槛的备考圈 |
| `code` 凭码 | **否** | 邀请码 / 邀请链接，免审 | ✅ | 熟人小圈子 |
| `private` 私密 | **否** | 仅圈主单个邀请，链接 24h 且一次性 | | 3–5 位密友 |

**三个附加开关**

| 开关 | 默认 | 可选值 | 为什么 |
|---|---|---|---|
| 人数上限 | **20** | 5–50 | 「小社区」得有上限，且让发码可控 |
| 谁能邀请 | **成员可邀，需圈主确认** | 仅圈主 / 成员可邀需确认 / 成员自由邀 | 只圈主发码裂变太慢，成员自由拉人又会失控 |
| 旁观态 | 开启 | 开 / 关 | 非成员可见 简介 · 人数 · 今日总时长，**不可见任何个人明细** |

**其他规则**
- 退出随时可行；**退出后 30 天内重进需圈主同意**（防骚扰）。
- 被移出 + 拉黑者，探索页也搜不到该圈子。
- **码只属于圈子**：`code` 档的邀请码/链接挂在圈子上，圈内房间不再单独发码；这与一期 F-21「房间码」冲突，二期落地时 F-21 整体迁移到圈子层。

### 8.3 准入 ≠ 授权（硬规则）

这是本功能最容易出事故的地方，两条链路必须分开写死：

| | 决定什么 | 谁控制 |
|---|---|---|
| **准入** | 能否看到圈子详情、成员名单、圈内看板、圈内房间 | 圈子的 `visibility` + 圈主审核 |
| **授权** | 我的时长 / 错题给谁看 | **本人**，圈主无权代开 |

共享档位四档（存在 `circle_member.share_level`）：

| 值 | 含义 |
|---|---|
| 0 | 仅自己（等于在该圈子隐身） |
| 1 | 圈内可见数字：今日时长、连续天数、科目占比 |
| 2 | 数字 + 错题统计（如「线代错了 3 道」，不含题目内容） |
| 3 | 数字 + 错题内容（题干、手写图、备注） |

- **默认 1**。升到 2 / 3 必须本人显式操作，且要一次性确认「圈内成员都能看」。
- 选 3 时，错题是**逐条投入错题池**，不是全库自动同步。
- `user.privacy_mode = 1` 是**总开关**：开启后所有圈子一律只显示「在线」，不看档位。
- 退出 / 被移出 → 该成员数字与其投入的错题同时撤下。

### 8.4 验收

- 非成员访问 `private` / `code` 圈子的详情或房间 → **403**，且探索页不出现
- 成员把档位调成 0，其他成员刷新后**立即**看不到其时序数字
- 成员退出后 60s 内，圈内看板不再出现该成员
- 圈主打开他人共享设置 → 无入口；直接调接口 → **403**
- 同一用户身处两个圈子，A 圈看不到他在 B 圈的时长

### 8.5 二期落地前置条件（先满足才动手）

1. **附件权限**从「登录可读」升级为「有权可读」。两种存法都要改：一期设计是七牛直传 + 存 `url` 字段（拿到 URL 即可访问）；当前预览实现是后端代理 `GET /attachments/view?key=`（登录 + 拿到 key 即可访问）。错题进圈子前，必须换成**按范围校验的短时效签名地址**（七牛私有空间 + downloadToken，或后端签发的 ≤10 分钟临时 URL）。
2. 错题共享四件套到位：主动投入 · 查看日志 · 签名 URL · 撤回即失效。
3. **用户协议与免责声明同步更新**：用户内容在圈内传播涉及版权与肖像，且截屏无法收回，必须写明边界。
