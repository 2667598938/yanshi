## 六、第一周开发顺序（建议）

| 天 | 任务 | 产出 / 验收 |
|---|---|---|
| D1 | 仓库初始化（main/dev 双分支）、前端 Vite+Vue3+Pinia、后端 FastAPI+SQLAlchemy+Alembic、`.env.example` | 前后端各能 `run`，`/health` 返回 200 |

| D2 | 统一响应体 / 错误码 / JWT / 依赖注入 / 日志 | `06-API` P0 部分落地，Postman 能打通 health 与 401 |
| D3 | 邮箱验证码 + 登录 + 刷新 + 退出 | 前端能登录进首页（屏 01） |
| D4 | 同步骨架：`sync_op_log` + `/sync/push` 幂等 + `/sync/pull` cursor | 断网创 3 条番茄 → 联网恰好 3 条，不重不丢（UC-06 验收） |
