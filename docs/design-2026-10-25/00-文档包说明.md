## 生成文档站点

`docs/` 是唯一真源，`docs/site/` 全部由脚本生成，不要手工改 HTML。

```bash
cd _src/yan-shi
python tools/build_site.py          # 重建 docs/site/*.html 与首页
python tools/build_site.py --check  # 只校验（口径 + 内链），非 0 退出
python tools/build_all.py           # 合并成单页 docs/site/all.html（发人/打印用）
```

脚本不依赖任何第三方包；`--check` 会核对表数量、枚举口径、接口路径与全部站内链接，当前全通过。
