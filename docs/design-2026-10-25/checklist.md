# 当前需求与验收核对清单

更新：2026-10-26。规则依据[当前规则](PRD-当前规则.md)，实际完成情况见[开发状态](../implementation-status.md)。下面未勾选表示需要逐项提交证据，不沿用旧文档的全量勾选。

## 账号、资格与管理

- [ ] QQ邮箱验证码/密码登录、续期、退出、封禁撤销凭据；实际邮件和关闭渠道行为明确。
- [ ] 邀请码批量生成/导出、一次兑换；VIP开通/续期/永久/指定到期/降级、本人通知与完整前后值审计。
- [ ] 普通用户功能申请、撤回、通过/驳回原因、撤销授权，资格即时生效且不代替对象归属。
- [ ] 管理员日常封禁保留数据，不一键清除账号学习信息，不编辑成员私人学习偏好，不查看隐私学习/AI/Key。
- [ ] 公告、审核、日志、邮件失败和运维操作入口真实可用；缺失指标显示未知或不展示，不能显示假0。

## 学习、错题与离线

- [ ] 倒计时到点自动结束并提醒，继续学习另开一轮；休息结束不自动开始专注。
- [ ] 正计时有效时长180分钟保护，单次暂停30分钟保护；恢复/后端/统计同口径。
- [ ] 任务含标题、科目、验收标准、预计分钟、日期和完成状态；自定义学习内容作为统计维度。
- [ ] 题目/解析各自多图、文本、思路、解析、标签、错误类型；删除自定义类型不清空历史意义。
- [ ] 复习间隔5分钟/30分钟/12小时/1天/2天/4天/7天/15天，复习与掌握流转可追踪。
- [ ] 日周月年分布、年度热力与跨日时区一致；有效时长与完成颗数区分。
- [ ] 本地业务写入和outbox原子；联网/前台/手动触发，失败保稿，幂等、冲突二选一、墓碑及账号隔离。
- [ ] 备份图片/时间节点可恢复，恢复仅新目录且不改在线隐私；真实手机/多设备/长断网单独验收。

## 小组、自习室与隐私

- [ ] 仅受邀同组默认互看任务/错题图片/番茄/热力/时长/状态，只读且不混入查看者本地任务。
- [ ] 单一隐私开关确认后在线生效，常驻提示；他人只见隐私中，不获知真实在线、位置或学习细节。
- [ ] 非隐私离线仍共享历史；本人隐私时继续使用学习和AI。管理员及图片、排行、在线计数无绕过。
- [ ] 网站在线、学习状态、当前房间分开；30秒/90秒心跳，进入/离场和退出成员区别，多设备不互相错误覆盖。
- [ ] 成员列表有文字状态与可见房间名；私密房间未获授权不暴露名称/码/跳转信息。
- [ ] 公开/私密房间、6位码、申请审批、房主管理、留言和排行；房型开关不冒充媒体推流。

## 内容、梦校和时间节点

- [ ] 资料和励志先审后公开，待审数据不经列表/详情/私图绕过；驳回原因与通知完整。
- [ ] 资料修改保留批准快照，新内容待审；查看按资格脱敏，作者个人备注永远只本人可见。
- [ ] 动态评论直接发布，管理员可删除违规内容并通知；二级回复，离线帖子、资料收藏、在线点赞。
- [ ] 梦校不限7所，个人增删改排序、多图封面与详情轮播，删空不重置；AI仅辅助文本，手动核实保存。
- [ ] 个人多时间节点、日期/首页开关/节点寄语、随机文案和长寄语；本人跨端，组员不共享。

## AI

- [ ] 本人私有多会话与消息持久保存；Key加密，只回掩码，不进本地业务库或学习同步。
- [ ] 真实模型目录、失败手填，服务商/地址/Key变化失效且忽略迟到响应；强制刷新、并发合并和六类安全错误。
- [ ] 目录不是推理可用/余额保证；不强制固定型号、不按名称猜能力，图片模型实际联调。
- [ ] 自动只读本人有界学习摘要，优先今日/待办，任务排序及验收标准、近7天完成数、当前全部逾期待办数、今日时长/颗数、近30天热力；预算/截断明确。
- [ ] 有效结构及消息ID才提供可见预览入口；普通确认文字不触发写库，字段合同一致。
- [ ] 用户逐条选择并手动确认后原子导入普通任务；来源、已导入状态与稳定回执，重复提交不重复新增。
- [ ] 撤销只删未改/未完成任务，原子版本判断，保留其余并提示；跨账号消息ID不可读/导入/撤销。
- [ ] 禁止DOM控制、通用Function Call/Agent编排和静默改学习数据；SSE异常与用量报告真实。

## 工程和交付

- [ ] 文档、接口、字段和实际迁移对应；SQLite/生产SQL差异有实测，未配置服务单列待配置。
- [ ] Git功能分支PR到dev，main经PR集成；不提交密钥、用户库、真实聊天或凭据。
- [ ] 自动测试、真实设备和真实供应商分别记录；未实现/部分/缺陷不因文档整理而关闭。

明确排除或未确认扩展只在当前规则维护，不把它们写成延期承诺。
