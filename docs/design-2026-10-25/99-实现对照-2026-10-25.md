# 当前要求与实现对照

更新：2026-10-26。规则见[统一规则](PRD-当前规则.md)。这是事实核查和待办，不把现有缺陷合理化为设计，也不因文档名称不同强制重建代码。

| 主题 | 事实及处置 |
|---|---|
| 学习存储 | learning_records承载subject/session/task/mistake等学习实体；learning_operations幂等，learning_changes增量。保留通用模型，关键字段后端校验。 |
| 独立业务表 | posts/comments、resources/resource_favorites、feature_requests/user_feature_grants、messages等实际存在，不能一概写不存在。 |
| AI会话 | ai_conversations/ai_messages实际两表；Key在user_ai_keys加密，不能使用过时ai_chat单表描述。 |
| 实际同步接口 | GET /api/v1/sync/records和POST /api/v1/sync/commands；文档不再保留另一套push/pull合同。 |
| 附件 | 归属/业务引用/受邀关系/隐私后鉴权读取，不是登录拿key就可读；私图代理no-store可保留。 |
| 房间码 | 6位，房间准入与小组学习共享分开；码不代替学习权限。 |
| 计时 | 用户已定倒计时到点完成本轮；原40分钟示例撤销，不再把自动结束本身当缺陷。 |
| 小组成员状态 | 返回status/statusText/isOnline/roomId/roomName；device_presence按设备聚合，离场与退出房间成员关系分离；隐私/私密位置后端过滤。 |
| AI确认按钮 | 有效消息ID/结构才显示导入；统一字段别名与校验，普通文字提供重新生成入口，逐项选择预览再确认，未解析不得写库。 |
| 导入/撤销 | 来源与导入回执持久保存；重试幂等、逐条选择与安全撤销已实现，版本变更或已完成的任务保留。 |
| 网盘审核 | 先审后公开，队列审批带版本检查；编辑保留批准快照，驳回原因通知，个人备注不进入审核/公开投影。 |
| 管理边界 | 删除账号接口拒绝，封禁保留数据；后台禁止改他人学习偏好，VIP日志含独立操作人/目标/前后值/原因。 |
| 管理页面 | 去除缺失指标假0及全平台人数/单房容量混用；个人院校归本人页面；新增审核、配置、批量邀请码导出、日志筛选与诊断。 |

原始评审曾基于main旧代码；现发布流程按dev→main及完整CI集成。不要根据旧分支或文档更新时间推断上线状态。数据结构以实际元数据/Alembic核查，需求以当前规则核查；完成状态以[开发状态](../implementation-status.md)核查，生产部署以[Azure手册](../../deploy/azure/README.md)与具体发布commit/digest为准。
