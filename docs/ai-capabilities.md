# AI能力、合同与当前差距

当前规则见[统一规则](design-2026-10-25/PRD-当前规则.md)第8～10节，完成状态见[开发状态](implementation-status.md)。需求统一维护，不按开发批次划分。

## 已有基础

本人会话和消息持久保存；Key后端AES-GCM加密、仅返回掩码；受控OpenAI兼容代理；模型目录/缓存/手填；真实SSE接口、会话并发租约、每日请求预算和供应商报告用量；本人AI/错题图片鉴权输入。

当前Key和聊天始终私有，不参与小组共享；隐私开关不阻断本人AI。账号资格、对象归属、模型能力和外部服务准备分别检查，管理员不能借管理权限看他人Key或对话。

## 模型目录目标

用户/服务商/地址/Key指纹隔离，配置变化清空旧选项并忽略迟到响应；主动强制刷新和single-flight；六类供应商错误安全分类、空目录独立提示、手填可用。目录只说明供应商声明模型可见，不保证余额或实际推理成功，不以固定型号验收。

已实现目录拉取/手填、主动强制刷新、进程内同 Key 请求合并和安全错误分类；切换配置会清空旧模型选项并忽略迟到响应。实际目录与模型可调用性仍需使用本人 Key 向对应供应商验证。

## 本人摘要目标

只读本人已同步账号数据，不访问组员、操作系统文件或DOM。默认待办至多20条按截止日排序，带标题/验收标准/预估；近7天完成数与当前全部逾期待办数，今日时长/颗数/状态，近30天活跃和总量。默认约1200 token预算可配置，按模型估算并保守截断、明确省略，不假装通用精确分词。

当前代码携带最多20条待办、最近3条完成任务、近7天完成数量及近30天热力汇总，受预算限制时继续截断并标明省略。聊天历史配置为0不关闭本人业务摘要。

## 任务建议、确认与安全撤销目标

后端验证tasks数组及title/accept_criteria/estimated_min/subject_id/due_date后，返回本人已保存消息ID和建议。日期未提供时在预览明确未设日期或补填；普通回复声称“需要确认”不构成任务。

前端展示可见的预览入口，用户逐条选择，明确确认后才原子写普通任务；手机操作区可达。相同确认重试返回原回执，来源和已导入状态可追踪。

撤销仅软删未修改、未完成任务；服务端原子比较导入版本与完成状态，已编辑/已完成项保留并提示。不能单凭source_message_id把整批全部删掉。

已实现逐条选择、确认弹窗、来源/已导入状态、重试幂等与安全撤销。同一回复只能确认一组选项，撤销后不可重导；需要重新让AI生成。缺少有效结构时不显示导入按钮，并提供重新生成可导入任务入口。

## 图片、服务与排除能力

当前单次至多4张本人图片，JPEG/PNG/WebP且每张不超过5MB；真实模型需支持视觉。图片输入和聊天会调用用户选择的外部供应商，实际模型、目录、费用和图片效果须本人配置后验证。仓库mock不代表供应商联调通过。

接口固定拒绝DOM/自动点击/通用Function Call或联网工具编排，不提供任意文件访问或静默改学习数据。Key不出现在前端明文回包、学习同步、日志或导出；原始供应商错误脱敏。
