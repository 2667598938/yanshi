基线：`dev@b99fb16f865b6110775783041e03bbd8e67a8e42`。本期处理代码审查确认的七组缺陷，以及真实设备验收发现的错题保存故障，保留现有功能；后续按个人学习闭环、自习室协作、授权与 AI、社区及开放准备继续分期。

## 修复与规则

| 编号 | 修复 | 验收结果要求 |
|---|---|---|
| B01 | 错题图片补传中断 | 题图、解析图首张或中途失败后，所有剩余 Blob 与顺序保留；成功 key 不重复上传；未完成图片补传的记录继续留在 outbox，不被云端残缺记录覆盖。 |
| B02 | 直接换号串库 | 只有当前处于游客库且目标库为空时才允许认领游客数据；账号 A → B 不迁移或清空 A；目标写入失败回滚；旧同步批次结束后再切换凭证与数据库。已有账号不自动混入游客数据或计时。 |
| B03 | 计时前后端口径 | `pauseAccum` 是累计已恢复暂停的毫秒数，用于时长扣减；`maxPauseMs` 是最长单次暂停的毫秒数，用于 30 分钟超时判定。多次暂停累计超过 30 分钟仍可正常完成。单次达到 30 分钟记 `quit/pause_timeout`。 |
| B04 | 房间写接口绕过准入 | 心跳、留言、目标墙必须已有成员身份；公开房间也需显式加入；私密房间需凭码或审批。被踢或退出后，心跳不能重新占位。 |
| B05 | 旧错题迁移未执行 | 登录、游客启动、账号切换、云端拉取后统一调用错题载入逻辑；旧日期字符串转毫秒时间戳、旧复习阶段映射到 8 节点；保留历史与 revision，迁移结果入队，重复载入不重复迁移。 |
| B06 | 励志配图上传契约 | API、存储 key 校验、投稿归属一致支持 `inspiration`；只能引用本人有效励志配图；待审/驳回图片其他普通成员不可读，审核通过后可读，删除后不可读；错题图不能挂入公开投稿。 |
| B07 | 备份解析图丢失 | 本地题图与解析图都转 data URL；云端 key 保留为引用；读取任何图片失败则整体导出失败，不静默跳过。导出不是云端附件的离线镜像。 |
| B08 | 真实界面收录错题无响应 | 标签、图片、复习历史等响应式数据写入 IndexedDB 前递归还原；新增、编辑、复习与 outbox 同事务提交；收录先落本地，图片后台补传；保存中禁用重复提交，失败时提示并保留输入。 |
| B09 | HTTP 局域网复制失败 | 房间详情/列表、邀请码、资料链接统一兼容复制；现代剪贴板接口不可用或被拒绝时尝试选中文本复制，两种方式均失败则显示可手动选择的内容，不误报“已复制”。 |

倒计时恢复时按先到的边界结算：25 分钟倒计时挂起 5 小时后仍按原定 25 分钟完成时刻保存；正向计时超过 180 分钟按 `quit/timeout` 保存 180 分钟。计划时长达到 180 分钟时沿用上限退出规则。暂停中手动结束的 `endedAt` 为进入当前暂停的时刻，未恢复暂停不再重复扣减。

旧计时记录如果没有 `pauseAccum`，服务端保留其有效 `actualSec`，并以墙钟间隔和 180 分钟上限约束。历史记录未提供单次暂停信息时，不把累计暂停推断为单次超时。已丢失的图片或已发生的跨账号误迁移无法靠此补丁自动还原，需使用原备份人工核对。

## 合并后人工验收

1. 在测试环境以 A 新建离线任务、错题与进行中番茄，直接登录 B，再切回 A；核对内容与待同步队列归属。另测游客首次登录与已有账号登录。
2. 创建含多张题图和解析图的错题，在补传第一张/中途断网，再联网；核对图片数量、顺序和另一设备回拉结果。
3. 分别测 25 分钟倒计时、正向计时、10 + 25 分钟多次暂停、单次 30 分钟暂停；同步前后时长、完成状态一致。
4. 使用非房间成员调用心跳、留言、目标接口，均应 403，且不新增成员；凭码/审批加入后可用；踢出后再次调用仍 403。
5. 使用旧版本日期字符串错题，启动、换号及云端拉取后均能出现在到期复习列表；历史记录保持。
6. 导出含两类本地图片的错题，检查 JSON 中 data URL 可还原；云端图片保持 key。损坏图片读取失败时不下载残缺文件。
7. 励志区上传、预览、投稿、管理员审批、另一普通账号查看图片依次验证；未审批/驳回不得被其他普通账号读取。
8. 在局域网 HTTP 地址点击房间码并粘贴，内容应一致；若浏览器拒绝自动复制，应出现可长按/全选的手动复制框。HTTPS 地址下另测现代剪贴板接口。邀请码和资料复制共用同一兼容逻辑。

尚需真实浏览器/手机、多设备联网与七牛生产配置验收；自动测试与本地启动检查不替代这些验收。此 PR 合回 `dev` 后再进行四人内测，通过后另发 `dev → main` 发布 PR。
