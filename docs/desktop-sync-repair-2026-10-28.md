## 2. 电脑端页面如何使用

960px 及以上显示左侧导航，可直接进入今日、专注、任务、错题、统计、AI、自习室、小组、资料、动态、梦校、消息和我的。管理员额外看到管理后台。登录页保留适合表单阅读的宽度。

| 页面 | 电脑布局与操作 |
| --- | --- |
| 今日 | 较宽屏幕使用学习主区与梦校/时间节点侧区；收起梦校后主区扩展；较窄电脑仍顺序展示 |
| 任务 | 左边看列表，右边新建/编辑；未选择任务时提示编辑入口；取消后返回提示，不遮住列表 |
| 错题 | 左边筛选题目，右边查看题图、思路、解析并复习；题图保留完整内容，仍可编辑或让 AI 讲解 |
| 记错题 | 科目、错因、标签与图片组成两列；笔记、解析和保存操作占整行 |
| 专注 | 左边计时环，右边科目、任务、学习内容、时长及开始按钮；主设备独占规则保持一致 |
| 统计 | 核心指标在上方，目标与完成情况并排，热力图占整行，其他图表按两列组织 |
| 自习室 | 房间信息占整行，成员和目标在主区，排行与留言在侧区；列表页按网格展示房间 |
| AI | 左侧保留会话列表，中间聊天；可新建、切换、删除、刷新本人会话；窄屏仍通过历史按钮打开列表 |
| 我的 | 账号卡、学习设置、工具、资料消息、隐私和备份按分区排列 |
| 后台 | 概览按网格排列；成员表格展示邮箱、角色、状态、会员与账号操作；搜索和分页同时适用于手机列表 |
| 资料与梦校墙 | 电脑使用多列卡片；编辑表单控制阅读宽度 |
| 弹窗 | 电脑居中并可滚动，手机仍为底部弹层；操作区和错误提示保持可达 |

后台搜索/分页针对接口当前已加载的列表，不宣称对服务器全库检索。梦校 AI 入口会把学校名称作为草稿带入对话，只提供文字辅助；不自动联网核实或回填。

## 4. 可照着操作的测试清单

1. 在电脑打开网站，确认左侧有完整导航。分别进入任务、错题、专注、统计、自习室、AI、我的和后台；页面工作区应使用电脑宽度。
2. 在任务页点击新建，确认编辑区与列表同时可见；填写、保存、再编辑、取消各做一次。手机上重复操作，编辑仍应为底部弹层。
3. 打开一条带多张题图和解析图的错题。电脑右侧应能完整查看并执行记住/忘记、编辑、让 AI 讲解；手机仍能打开详情。
4. 在“我的梦校弹幕”写一句私人寄语并保存，再修改默认专注时长，同时新增任务。点击立即同步，应成功；另一个设备同步后应能看到本人相同设置和任务。
5. 若以前曾因设置返回 400，直接刷新新版并立即同步；不要清空本地数据。待同步数量应恢复下降，原任务仍存在。
6. A 登录后打开自习室，再退出并登录 B；选择梦校时不能出现 A 独有院校。快速 A→B→A、断网后换号也重复检查。
7. 在梦校管理新增院校、改名、删除；返回首页、我的、梦校墙、自习室时，无须刷新整页就能得到新目录。
8. AI 新建真实对话、切换历史、删除会话；没有配置本人 Key 时应有配置引导。正式页面不再出现“模拟生成”。
9. 管理后台选择成员，搜索邮箱，翻页，打开会员调整后取消。手机上的同一列表应仍可搜索和翻页。
10. 开启隐私模式或断网时检查顶部提示；打开长弹窗，确认保存/取消/错误提示可见。拖窄电脑窗口，并在浏览器 125% 缩放下重复关键操作。
