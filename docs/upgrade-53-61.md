# #53–#61 界面、存储和开放改造

本次按用户的新规则替代旧版四人房、生产强制七牛及主管理员学习界面规则。当前主管理员由 `role=admin` 且邮箱等于部署的 `ADMIN_EMAIL` 标识；其他管理员可保留学习界面。不要修改 `ADMIN_EMAIL` 来重命名已有主管理员。

## 界面

- 首页首屏依次展示一行初试倒计时、三项今日概览、专注入口/运行计时与暂停结束、每日目标和可直接新增勾选的任务。梦校管理移到“我的→学习内容”。
- “我的”只保留学习设置、学习内容、账号与会员、小组与自习室、数据与关于五个入口。原有设置处理器和弹窗保留在二级视图。
- 护眼绿为主色，基础字号/间距/圆角集中到 `tokens.css`。大号计时展示保留独立字号。修复弹窗末尾按钮强制白底的覆盖规则；主、次、危险按钮具有独立样式。
- 底部五个平铺入口：首页、统计、自习室、AI、我的。专注入口位于首页。
- 主管理员登录/刷新会话后只进入 `/admin` 及后台二级页，不显示学习导航、底栏或学习状态组件，也不运行学习数据同步/在线心跳。后台提供退出和修改密码。

## 图片

- `IMAGE_STORAGE=local` 支持生产；目录仍是容器持久卷中的 `/var/lib/yanshi/uploads`，API 鉴权与附件权限校验保留，不设置公开静态图片目录。
- SQLite 和图片持久卷在更新时均保留。已有七牛附件按每条附件记录的存储后端读取，不进行隐式搬迁。
- 每个账号的 Dexie v5 增加 `imageCache` 表，包含 key/blob/size/lastAccessedAt；上传成功时缓存 Blob，统一 `BlobImage` 优先读缓存，否则鉴权下载并缓存。
- 缓存限制100MiB，按最近访问清理；失败不影响已上传的数据，账号切换时旧请求不能写入或显示给新账号。缓存属于可淘汰副本，服务器文件是权威数据。
- 请求浏览器 `navigator.storage.persist()`；是否授予由浏览器决定，不承诺浏览器永远不清缓存。
- 日常一致性备份包含数据库和本地图片；仍需配置独立存储副本。

## 房间

- 新建只接受 `text_room` 和 `av_room`。文字房默认50人，可选20/50/100；mesh音视频房6人；SFU容量25，需要额外部署并配置 `ROOM_SFU_ENABLED`/`ROOM_SFU_URL`，当前只预留开关。
- 迁移 `d4f6a8b0c2e4` 保留旧房间、成员、留言和目标，转换旧类型并扩大原四人文字房容量。恢复旧数据库应同时恢复兼容代码，不能盲目缩容。
- 页面列表仅显示公开房；创建/凭码入口置顶。API仍允许已确认成员取得本人的私密房间信息和邀请码。私密房仅凭房间码加入，其申请入口返回410；公开房保留申请、房主审批与共享确认，历史私密房申请仍可查看或拒绝，不能通过审批绕过房间码。
- mesh使用鉴权WebSocket信令、房间成员检查、最多6个连接、消息大小和频率限制；每条消息重验会话有效性及成员资格。访问token通过握手后的消息传递，避免出现在URL日志中。
- 摄像头/麦克风仅在用户点击后申请，退出时关闭轨道。默认使用STUN，受限网络需配置TURN；实际音视频连通性必须通过多台真实设备验收。
- 启用时在 `FEATURES` 增加 `av_room`，并合并部署参考中的WebSocket专用location。继续使用单worker；多进程部署需要共享信令基础设施。

## 登录和开放配置

- 邮箱通道保留QQ邮箱账号密码、验证码注册/登录和找回；无须QQ互联。
- GitHub授权使用state校验、PKCE、一次性票据与httpOnly refresh Cookie；只采用GitHub已验证邮箱，优先已验证主邮箱，绑定已存在的相同邮箱账号。持久身份使用GitHub用户ID，不使用可变用户名。
- 新增 `GITHUB_CLIENT_ID`、`GITHUB_CLIENT_SECRET`。缺少任一凭据时不展示GitHub登录入口。
- OAuth回调：`https://boang.fun/api/v1/auth/oauth/github/callback`。
- 正式开放需 `AUTH_PASSWORD_ONLY=false`、`AUTH_CHANNELS=email,github`、`ACCOUNT_MAX_USERS=10000`、真实SMTP。注册开关同时涉及环境初始值和数据库后台配置；配置完成后再打开数据库注册开关。
- 保留现有 `JWT_SECRET`、`AI_KEY_ENC_SECRET`，不要在升级时重新生成。服务器密钥不进入代码、PR或构建日志。
- 公共配置在生产SMTP未配置时不广告开放邮箱注册和验证码登录。

外部服务凭据、GitHub真实OAuth回调、真实SMTP送达、手机及电脑视觉、多设备音视频需在生产配置后继续验收；自动化测试的mock不能代替上述检查。
