# 研时上线部署步骤（备案通过后照做）

> 服务器：上海 ECS `<SERVER_IP>`，Ubuntu 24.04，域名 `<YOUR_DOMAIN>`。
> **备案审核期间服务器保持关机、Nginx/后端不启动、DNS 三条记录暂停**——以下全部等 ICP 备案通过后再执行。

## 0. 前置确认
- [ ] ICP 备案通过，拿到备案号。
- [ ] 阿里云 DNS 恢复 `@`、`www` 两条 A 记录指向 `<SERVER_IP>`（`_dnsauth` 那条可删）。
- [ ] 服务器开机，SSH 能登录。**上线前先改 root 密码**。

## 1. 服务器基础环境
```bash
apt update && apt install -y python3-venv python3-pip nginx git
```

## 2. 部署后端
```bash
cd /root
git clone <你的仓库地址> yanshi-server      # 或用其他方式上传代码
cd yanshi-server
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 3. 生产环境变量
复制 `.env.example` 为 `.env`，按下面改：
```ini
ENVIRONMENT=production
DATABASE_URL=sqlite:////root/yanshi-server/data/prod.sqlite
JWT_SECRET=<填 48 位以上随机串：python -c "import secrets;print(secrets.token_urlsafe(48))">
MAIL_CONSOLE=false
SMTP_HOST=smtp.qq.com
SMTP_PORT=465
SMTP_USER=<你的邮箱>
SMTP_PASSWORD=<QQ 邮箱 SMTP 授权码>
SMTP_FROM=<你的邮箱>
ADMIN_EMAIL=<管理员邮箱>
ADMIN_PASSWORD=<改成新的强密码>
IMAGE_STORAGE=local          # 先本地存储跑通；要用七牛再改 qiniu 并填下面
QINIU_ACCESS_KEY=<七牛 AccessKey>
QINIU_SECRET_KEY=<七牛 SecretKey>
QINIU_BUCKET=<桶名>
QINIU_S3_REGION=cn-south-1
QINIU_DOMAIN=<图片 CDN 域名>
VOLC_API_KEY=<火山方舟 API Key>
VOLC_MODEL=doubao-seed-2-1-pro-260915
```

## 4. 建表 + 初始化
```bash
mkdir -p data
.venv/bin/alembic upgrade head
.venv/bin/python -m app.seed
```

## 5. 注册系统服务
```bash
cp deploy/yanshi.service /etc/systemd/system/yanshi.service
systemctl daemon-reload
systemctl enable --now yanshi
systemctl status yanshi          # 确认 active
curl http://127.0.0.1:8000/health
```

## 6. 部署前端
在本地 `D:\KAOYAN\yanshi\web` 执行 `npm run build`，把 `dist/` 上传到服务器 `/root/yanshi-web/dist`
（开发期前端通过 Vite proxy 访问后端；生产由 Nginx 同源托管，无需跨域）。
```bash
mkdir -p /root/yanshi-web
# 用 scp/rsync 上传 dist 内容后：
cp /root/yanshi-server/deploy/yanshi.nginx.conf /etc/nginx/conf.d/yanshi.conf
nginx -t && systemctl reload nginx
```

## 7. HTTPS（备案通过后，可选但建议）
```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d duzhi.xin -d www.duzhi.xin
```

## 8. 七牛图片域名（可选，先本地存储也能跑）
- 七牛控制台为 `sharearea` 绑定 `img.duzhi.xin`，到阿里云 DNS 加 CNAME 指向七牛给的地址。
- `.env` 把 `IMAGE_STORAGE` 改成 `qiniu`，重启服务。

## 9. 每日备份
```bash
crontab -e
# 每天凌晨 3:17 备份，保留最近 14 份
17 3 * * * cd /root/yanshi-server && .venv/bin/python scripts/backup.py >> /var/log/yanshi-backup.log 2>&1
```

## 10. 合规收尾（必须）
- [ ] 网站底部挂 ICP 备案号并链接到 https://beian.miit.gov.cn 。
- [ ] 上线后 30 日内到全国互联网安全管理平台做**公安备案**，备案号挂底部。
- [ ] 站内放「用户协议」「隐私政策」，注册必须勾选。
- [ ] 定位保持「学习工具 / 计时器」，不出现平台/社区/论坛字样；自习室仅 4 人、无视频、无公开内容。
- [ ] 日志（登录/审计）保留 ≥6 个月。

## 旧产物清理
旧版遗留：`/root/yanshi_server`、`/etc/nginx/conf.d/yanshi.conf`（旧，反代 8002）、`fastapi-yanshi.service`。
部署新版前先停旧服务并移除旧配置，避免端口/路径冲突：
```bash
systemctl disable --now fastapi-yanshi 2>/dev/null
rm -f /etc/nginx/conf.d/yanshi.conf.bak   # 确认后再清理旧目录
```
